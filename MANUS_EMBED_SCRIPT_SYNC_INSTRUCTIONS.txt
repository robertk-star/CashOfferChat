CashOfferChat Embed Script Sync Phase

Apply this ZIP at the CashOfferChat project root.

This phase makes every Admin and Client widget-site page display the current canonical widget install script.

The install script shown in both admin and client portals must now be:

<script src="https://www.cashofferchat.com/widget.js?v=embed-sync-canonical-api-20260606d" data-site-id="SITE_ID_HERE"></script>

Do not show or copy the old script:

<script src="https://cashofferchat.com/widget.js" data-site-id="SITE_ID_HERE"></script>
<script src="/widget.js" data-site-id="SITE_ID_HERE"></script>

Files that must be present/updated:

1. src/lib/widgetEmbed.ts
2. public/widget.js
3. src/app/admin/sites/page.tsx
4. src/app/admin/sites/[id]/page.tsx
5. src/app/client/sites/page.tsx
6. src/app/client/sites/[id]/page.tsx
7. src/app/admin/businesses/[id]/page.tsx
8. src/app/admin/onboarding/page.tsx
9. src/app/sellmyhousetodayanywhere/page.tsx
10. src/app/api/widget/settings/route.ts
11. src/app/api/widget/events/route.ts
12. src/app/api/chat/route.ts
13. src/app/api/leads/route.ts

After deployment, verify:

1. Open https://www.cashofferchat.com/widget.js
2. Confirm the file contains: embed-sync-canonical-api-20260606d
3. Confirm the file contains: https://www.cashofferchat.com
4. Open /client/sites and confirm the embed code uses www.cashofferchat.com and includes ?v=embed-sync-canonical-api-20260606d
5. Open /admin/sites and confirm the same.
6. Open sellmyhousetodayanywhere.com and run this in the browser console:
   window.CASHOFFERCHAT_WIDGET_VERSION
   It should return: embed-sync-canonical-api-20260606d
7. Run:
   window.CASHOFFERCHAT_WIDGET_API_BASE
   It should return: https://www.cashofferchat.com

SQL migration needed: No
Vercel ENV needed: No new variables

Optional ENV:
NEXT_PUBLIC_WIDGET_SCRIPT_ORIGIN can be set later if the widget script host changes, but it is not required.
