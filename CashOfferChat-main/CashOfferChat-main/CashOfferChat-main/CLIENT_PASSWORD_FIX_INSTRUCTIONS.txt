CashOfferChat Client Password/Admin Client Save Fix

Apply these files at the project root. They improve the admin client user save route so password errors are specific instead of generic.

Files included:
- src/app/api/admin/clients/[id]/route.ts
- src/app/admin/clients/[id]/page.tsx

The ZIP also includes the same files under CashOfferChat-main/ in case your GitHub repo still contains a nested duplicate folder. Ideally, delete the nested duplicate folder later so Next.js does not compile two app trees.

After upload, run:
npm run build

Then test:
1. Go to /admin/clients/[client-id]
2. Try saving with a password shorter than 8 characters.
3. You should see: Password must be at least 8 characters.
4. Try saving with a password at least 8 characters.
5. You should see: Client user saved and password updated.
