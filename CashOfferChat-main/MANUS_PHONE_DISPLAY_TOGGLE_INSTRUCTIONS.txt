CashOfferChat Phone Display Toggle Phase

Apply this ZIP at the active CashOfferChat project root.
Do not place files inside a nested CashOfferChat-main folder.

Confirm these active-root files are updated:
- src/app/client/settings/page.tsx
- src/app/api/client/settings/route.ts
- src/app/admin/settings/page.tsx
- src/app/api/admin/settings/route.ts
- src/app/api/widget/settings/route.ts
- public/widget.js
- src/lib/widgetEmbed.ts

After deploy:
1. Go to /client/settings.
2. In the Widget section, use the new "Show phone number / call button in the widget" checkbox.
3. Save settings.
4. Open the external site using the updated embed script from /client/sites.
5. If unchecked, the widget should not show the phone/call button.
6. If checked and the business phone is filled in, the widget should show the call button/phone number.
