Apply this ZIP at the project root. Do not create a nested CashOfferChat-main/CashOfferChat-main folder.

Before deploying, verify these files exist in the project root:

1. src/app/admin/faqs/page.tsx
2. src/app/api/admin/settings/faqs/import-defaults/route.ts
3. src/lib/defaultFaqKnowledge.ts
4. src/app/admin/settings/page.tsx contains the text: Import Top 100 FAQs

Then run:
npm run build

After deployment, verify:
https://www.cashofferchat.com/admin/faqs no longer returns 404.
https://www.cashofferchat.com/admin/settings includes Import Top 100 FAQs after logging in.
